# 💌 말씀 마니또

인스타로 모집한 크리스천 10명이 2주 동안 익명으로 말씀 카드를 주고받고, 마지막 날 서로 공개하는 웹입니다.

- 빌드 과정이 없는 정적 사이트(HTML/CSS/JS)라서 폴더를 그대로 올리면 됩니다.
- DB는 Supabase 무료 플랜을 씁니다.
- `js/config.js`가 비어 있으면 **데모 모드**로 동작합니다. 데이터는 그 브라우저에만 저장돼요.

## 화면

| 주소 | 화면 |
|---|---|
| `/#/` | 모집 페이지 (인스타 프로필 링크로 걸 주소) |
| `/#/join` | 신청 |
| `/#/login` | 로그인 (닉네임 + PIN) |
| `/#/home` | 내 마니또, 기도제목, D-day |
| `/#/send` | 말씀 카드 보내기 |
| `/#/cards` | 받은 카드 / 보낸 카드, 스토리 이미지 저장 |
| `/#/reveal` | 공개 |
| `/#/admin` | **운영자 페이지** (링크는 나만 알고 있기) |

## 실제로 오픈하기 (약 15분)

### 1. Supabase 준비
1. https://supabase.com 에 가입하고 **New project**를 만듭니다. Region은 `Northeast Asia (Seoul)`을 고르세요.
2. 왼쪽 메뉴에서 **SQL Editor**를 열고 `supabase/schema.sql` 내용을 전부 붙여넣습니다.
3. ⚠️ 맨 아래 `'여기에-관리자-비밀번호'`를 **나만 아는 8자 이상 비밀번호**로 바꾼 뒤 **Run**을 누릅니다.
4. **Project Settings → API**(또는 **API Keys**)에서 아래 두 값을 복사합니다.
   - Project URL
   - `anon` `public` 키 (새 프로젝트라면 `publishable` 키)

### 2. 설정 파일 채우기
`js/config.js`를 열어서 값을 넣습니다.
```js
supabaseUrl: 'https://xxxx.supabase.co',
supabaseAnonKey: 'eyJ...  또는 sb_publishable_...',
contactInsta: '내_인스타_아이디',
```
> anon/publishable 키는 공개되어도 괜찮은 키입니다. 데이터는 DB 함수로만 접근할 수 있게 막혀 있어요.
> **service_role / secret 키는 절대 넣지 마세요.**

### 3. 배포 (택 1)
- **Netlify Drop (가장 쉬움)**: https://app.netlify.com/drop 에 `malsseum-manito` 폴더를 통째로 끌어다 놓으면 주소가 나옵니다.
- **Vercel**: 새 프로젝트를 만들고 이 폴더를 업로드합니다. Framework는 `Other`, Build Command는 비워 둡니다.

### 4. 운영 순서
1. `주소/#/admin`에 들어가 관리자 비밀번호로 로그인하고, **설정**에서 기수 이름, 정원, 시작일, 공개일을 정합니다.
2. **모집 글 복사** 버튼으로 문구를 복사해 인스타에 올리고, 프로필 링크에 사이트 주소를 겁니다.
3. 다 모이면 **모집 마감 → 매칭하기 → 진행 시작하기**를 차례로 누릅니다.
4. **시작 안내 DM 복사**로 문구를 복사해 참여자들에게 DM을 보냅니다.
5. 진행 중에는 ⚠️ 표시가 뜬 사람(카드를 안 보낸 사람)에게 **리마인드 DM**을 보냅니다. 카드를 못 받는 사람이 있으면 **천사 카드**로 대신 보내주세요.
6. 공개일에 **공개하기**를 누르고 **공개 안내 DM**을 보냅니다.
7. 다음 기수는 **시즌 초기화** 후 다시 시작합니다.

### 파일을 고친 뒤에는
`index.html` 안의 `?v=20261008` 숫자들을 새 날짜로 바꿔서 함께 올려 주세요. 안 바꾸면 방문자의 브라우저가 최대 10분 정도 예전 파일을 계속 쓸 수 있어요.

### 자주 생기는 일
- **PIN을 잊었어요** → 운영자 페이지에서 그 사람 옆의 `PIN` 버튼으로 새 PIN을 정하고 DM으로 알려줍니다.
- **중간에 빠지는 사람** → `내보내기`를 누르면 마니또 고리가 자동으로 다시 이어집니다. 마니또가 바뀐 사람에게 DM으로 알려주세요.
- **부적절한 카드** → 운영자 페이지의 "모든 카드"에서 `숨기기`를 누릅니다.

## 로컬에서 미리보기
**윈도우** (설치할 것 없음)
```
powershell -ExecutionPolicy Bypass -File serve.ps1
```
**맥** (기본으로 깔려 있는 python3 사용)
```
python3 -m http.server 5173
```
두 경우 모두 http://localhost:5173 에 접속하면 됩니다. Claude 데스크톱 앱에서 이 폴더를 열면 `.claude/launch.json` 설정으로 미리보기를 바로 띄울 수 있어요. 데모 모드의 관리자 비밀번호는 `admin`이고, 운영자 페이지에서 **가상 참여자 채우기**로 흐름 전체를 시험해 볼 수 있습니다.
